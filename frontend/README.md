# Фронтенд «Копилки»

Интерфейс личного финансового трекера: React 18, TypeScript, Vite и Recharts.
Работает без бэкенда в тестах — сетевые вызовы подменяются.

Описание проекта, список решений и разбор trade-off — в [README.md](../README.md)
в корне репозитория.

## Что внутри

| Путь | Что это |
|---|---|
| `src/api/client.ts` | Обёртка над `fetch`: базовый адрес, JSON, типизированная ошибка |
| `src/api/kopilka.ts` | Все адреса эндпоинтов — ни одного URL в компонентах |
| `src/auth/` | Контекст аутентификации и хранение токена |
| `src/components/` | Экраны и виджеты: сводка, графики, формы, списки |
| `src/utils/money.ts` | Форматирование денег: сумма остаётся строкой до вывода |
| `src/utils/period.ts` | Арифметика месяцев — без календарных дат |
| `tests/` | Тесты клиента, форм и главного экрана |

## Запуск локально

```bash
npm ci          # точные версии зависимостей из package-lock.json
cp .env.example .env   # адрес API, по умолчанию http://localhost:8000
npm run dev
```

Фронтенд на <http://localhost:5173>, API — на <http://localhost:8000>.

## Проверки

```bash
npm run lint           # ESLint
npm run build          # проверка типов (tsc --noEmit) и сборка
npm test               # Vitest
npm run test:coverage  # Vitest и отчёт о покрытии
```

Типы проверяются во время сборки: интерфейс и API разъехаться не могут,
потому что контракт описан в одном файле `src/types.ts` и дублируется в
схемах Pydantic на бэкенде.
